MINDUSTRY BROWSER PORT - SERPULO CAMPAIGN

This ZIP is a static website. Extract it and serve the extracted directory over
HTTP. Do not open index.html directly.

Python example:
  python3 -m http.server 8080

Then open:
  http://localhost:8080

Ground Zero starts automatically until it has been captured. Later sessions
open on the Serpulo world map. Controls are the normal Mindustry desktop
controls. Campaign data is saved in this website origin's IndexedDB storage.

This is an unofficial GPL-3.0 build. Multiplayer, mods and audio are currently
disabled. Corresponding source is provided in mindustry-browser-source.zip.
